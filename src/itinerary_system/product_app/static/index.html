About this prototype

This local, fixture-first product reads immutable research artifacts. W3 persists typed drafts, runs deterministic repair, and independently evaluates eligible children; acceptance remains disabled until the W5 repository transaction exists.

Unsupported route policies remain unavailable rather than simulated. This interface is not E5 participant-study evidence.
