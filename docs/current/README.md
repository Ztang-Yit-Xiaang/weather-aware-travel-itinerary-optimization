- `current_score_audit.md`: audit of the current repository scoring model, including safe claim language, limitations, and repair-paper implications.

## Relationship to Literature

The compact repair-gap literature matrix lives in `docs/literature/literature_matrix_repair_gap.md`. Keep that matrix with the literature materials because it compares papers and identifies the research gap.
